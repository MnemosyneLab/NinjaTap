# 操作这台手机

CLI 和 MCP 的通用操作见 [Agent 操作指南](../host/ninjatap/guide.md)。这里记录这台 HONOR DNY-NX9 的实测细节。另见 [设计](design/NinjaTap.md) 和 [触控实测](devices/DNY-NX9.md)。

屏幕是 1264×2736，原点在左上角，旋转必须是 0。工具报错就停，不要接着编下一个坐标。`screen_off` 表示屏幕灭了：截图和触控都会被拒绝。电源键和这台触摸屏在同一个输入设备上，不能靠注入去点亮屏幕，让人把屏幕打开。

USB 拔掉不影响局域网里的服务。服务停了，或者 App 里点了停止，这条链路就断了。操作时不要点 NinjaTap 界面上的「停止」。

## 先看图，再决定点哪里

`screenshot` 默认只给全帧 PNG。需要一份文字列表时，用 CLI 的 `--ocr` 或 MCP 的 `ocr: true` 显式开启。列表里的坐标是文字的中心，不是图标的中心。桌面图标的文字在图标下面大约 110 像素。点文字那一行，桌面经常没有反应。点图标本体。

界面上的中文和英文都能读。表情符号、很小的字、图片里的艺术字仍会错。小红书在装上之前，文字列表里没有出现过「小红书」或 rednote。认不准的时候看 PNG，不要只靠那份列表。

要留下这一帧，给 `screenshot` 一个绝对路径，并且以 `.png` 结尾。同一帧会写到磁盘，MCP 调用结果里仍有 PNG，只有开启 OCR 才会附文字。文字稿用返回的文字自己写。不要为了存图再去调手机的 HTTP。

同一下操作每次的路径、压力和接触面积都不同。点击会偏几个像素。`drag`、`slow_drag`、`flick`、`hold_drag` 的起点和终点是给定的点。

一次手势做完，等大约半秒再截图或做下一笔。上一笔的翻页动画还没停时，下一笔会把它取消，页面弹回去。

## 三种移动

| 想要的结果 | 工具 |
| --- | --- |
| 把东西拖到一个确定的点再放下 | `drag`。先到位，再停大约半秒 |
| 列表或页面跟着手指走，抬手就停 | `slow_drag`。抬手时大约 115px/s |
| 回桌面、返回、翻页、把列表甩出去 | `flick`。大约 250ms，还在快速移动时抬手 |

`drag` 太慢，系统把它当成页面内部的滚动。用它从屏幕底部往上滑，回不到桌面，也翻不了页。在桌面上慢拖一小段，页面会跟一下然后弹回原页。

## 系统手势

这台手机底部是一条手势条，不是三颗按键。

从手势条快速上滑会离开当前应用，回到桌面。可用的一笔是 `flick(632, 2680, 632, 1500)`。起点改到大约 y=2460 时，滑的是底栏图标，抽屉没有打开。不要用这一笔当「打开全部应用」。

普通返回和回桌面直接用 `back` 和 `home`。需要测试系统边缘手势时用下面的轨迹。小按钮可以用 `tap_exact(x, y)` 固定落点。

返回是从屏幕左缘或右缘向内快甩。翻页时起点离左右边缘留出大约 140 像素，否则会变成返回。屏幕宽 1264，翻页的起点放在 x=280 到 x=1080 之间。

桌面翻页在空白壁纸上做，不要从图标、文件夹或小组件上开始。手指从左向右快甩，到上一页；从右向左，到下一页。已经成功的一笔是在 y=1600，`flick(280, 1600, 1080, 1600)`，从 SAI / NinjaTap 那一页到了左边的应用页。

竖着滑过「My list」股票小组件，滚的是小组件里的报价，桌面不动。小组件在的时候，空白壁纸在它上方和右侧。

时钟那一页再向左是 Google 探索信息流，不是另一页桌面。在顶部的横向标签上横滑，出不了这个信息流。从文章正文横滑才能回到时钟页，例如 y=2000、从 x=1100 到 x=180。

## 桌面

五页，从左到右大致是：

1. 时钟、Google 文件夹、Essentials 文件夹。底下一排是 Gemini、Play Store、Photos、FIClash。
2. Tools、YouTube、Grok、Telegram 这类图标。
3. Legado、bilibili、KernelSU。rednote 装好后出现在这一页右下角。
4. SAI、NinjaTap、文件夹 Ph。有时下面还有「My list」小组件。

图标列的 x 大约是 194、486、776、1067。最底下一排图标的 y 大约是 2000，文字在 y=2130 附近。

底栏没有文字，从左到右是电话、信息、Chrome、相机，中心大约在 y=2520。

Play Store 在第 1 页。图标中心大约是 (490, 2000)。点文字「Play Store」没有打开它。

## 点下去之前

权限、条款、安装确认这类对话框，先停下来看用户要不要继续。rednote 打开后停在 Privacy & Terms，没有替用户点 Agree。

Play 商店里按钮从 Install 变成百分比，再变成 Open。装完之前不要点 Cancel。

两列信息流里，慢拖落在其中一列的空白内容上。rednote 底部中间大约 (632, 2587) 是发布按钮，底栏文字在 y=2610 附近。从那里起笔会点到按钮，或者滑进系统手势。

点卡片要看下一帧是不是整页。偏一点会打开半屏抽屉。那不是正文。关掉抽屉，再点卡片中间。

## 输入文字

一整段字用 `write_clipboard` 放进剪贴板，长按输入框，再点「粘贴」。不要逐个字母点键盘。搜索框里已有建议词时，接着输入或粘贴会换掉它，不用先逐字删。

只点一下用 `tap`。

键盘已经打开，而且这几下的位置都在当前这一帧里，用 `taps`。参数是 `points`，每一项是 `x` 和 `y`，按给出的顺序点。这些点放进同一次注入。每下仍偏几个像素，接触面积每次重抽，两下之间空 40 到 110 毫秒。一次最多 32 个点。有一个点在屏幕外，整段都不会播放。

`taps` 适合一个拼音音节、连续退格、或点完搜索。不适合整段文字。也不适合点下去界面就会变的地方，因为这几下中间没有截图。一个音节点完先截图，等候选栏出来，再单独点候选。候选的位置要等它出现，不要写进同一次 `taps`。退格的位置看这一帧，不要把右下角当成删除。

选中一段能看见的文字用 `hold_drag(x1, y1, x2, y2)`。同一根手指先在起点停住，再拖到终点，终点就是给出的点，停一下再抬。起点停多久用 `ms`，单位是毫秒；不传大约 500。时长偏开大约 8%，至少偏 40 毫秒。小于 1 不会播放。不要用 `long_press` 再加 `drag` 来拼，中间一抬选区就断了。也不要在文字上用 `drag`：它一按下就开始走，停在终点，从屏幕左缘拖过文字还会被当成返回。

起点的 x 要在 140 到 1123 之间。更靠边就不会播放。终点可以在屏幕里的任意位置。

这一笔只负责选中。选完截图，确认选区盖住要的字，再点「复制」，然后 `read_clipboard`。长过一屏的，先选这一屏并复制，再用 `slow_drag` 把后面滚出来，接着选。

`read_clipboard` 读当前纯文本。剪贴板没有文字时返回空字符串。读失败是错误，不要当成空剪贴板。写入不会自动粘贴。
