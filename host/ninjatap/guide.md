# NinjaTap Agent 操作指南

适用于通过 CLI 或 MCP 操作已配对的 HONOR DNY-NX9。手机需要亮屏、保持竖屏，并运行 NinjaTap 服务。CLI 的 `ninjatap <命令> --help` 可查看参数。MCP 使用同名工具和命名参数。

## 默认操作循环

1. 用 `ninjatap screenshot /tmp/ninjatap-screen.png` 获得 PNG。需要用文字定位按钮、输入框、菜单和文件名时，用 `ninjatap screenshot --ocr /tmp/ninjatap-screen.png` 或在 MCP 调用里传 `ocr: true`，可得到每条可读文字的中心坐标。图标、缩略图、截图内的文字和识别不清的标签用 PNG 确认。
2. 根据最新画面选择一个目标，普通按钮和卡片优先用 `ninjatap tap X Y`。小目标、贴近其他控件的目标或点位测试才用 `tap_exact`。坐标取自 **1264 × 2736 的原图**，原点在左上角。桌面应用点图标本体，OCR 给出的应用名通常在图标下方。
3. 等当前操作返回、页面稳定后再截图，确认结果再继续。连续几点只有在键盘布局或控件位置保持稳定时才用 `taps X1 Y1 X2 Y2 ...`。

普通截图默认不调用 OCR。显式开启 OCR 后，如果识别失败，仍会得到 PNG 和识别失败提示；CLI 会继续保存图片。

## 导航和触控

| 目标 | 命令 |
| --- | --- |
| 回桌面后打开应用 | `home`，截图定位应用图标，再 `tap X Y` |
| 关闭菜单、返回上一页 | `back`，再截图确认回到了哪一层 |
| 缓慢阅读信息流 | `slow_drag X1 Y1 X2 Y2`，从正文或卡片的空白处起手 |
| 快速翻页、甩动列表 | `flick X1 Y1 X2 Y2`，横滑从屏幕内侧起手以避开系统返回手势 |
| 拖动控件到指定位置 | `drag X1 Y1 X2 Y2`，到终点会稍作停留 |
| 打开长按菜单 | `long_press X Y MS`，根据画面选择菜单项 |
| 按住后连续拖动 | `hold_drag X1 Y1 X2 Y2 [MS]`，起点与左右屏幕边缘至少相距 140 px |
| 双指缩放 | `pinch CX CY START_GAP END_GAP`，间距单位是像素 |

## 搜索、复制和文件传输

- **搜索或填写文字**。点进输入框。`write_clipboard '要输入的文字'` 会替换手机剪贴板，接着长按输入框并点「粘贴」。截图确认实际输入的文字，再点「搜索」或键盘上的提交键。如果要保留原有剪贴板，可以用当前输入法，通过 `taps` 输入一组拼音，看清候选词后再选。
- **复制手机上的可见文字**。用 `hold_drag` 选中一段文字，截图核对选区，点「复制」，再用 `read_clipboard` 取回纯文本。看到空输出时，结合退出码区分空剪贴板和读失败。
- **把 App 保存的图片传回电脑**。用 App 自带的「保存」，确认保存成功。回桌面打开「文件」或相册，在最近项目里找到对应的缩略图，打开文件信息取得完整手机路径。然后执行 `ninjatap pull '/sdcard/DCIM/手机显示的文件名.jpg' './saved.jpg'`。这会下载已保存的文件。作者关闭下载时，可以改选允许保存的笔记。
- **把电脑文件传到手机**。例如 `ninjatap push './photo.jpg' '/sdcard/Pictures/photo.jpg'`。手机端支持共享存储，包括 `/sdcard/` 和 `/storage/emulated/0/`。目的地父目录须已存在，已有文件受保护。上传媒体后等待 Android 刷新索引，再从相册或目标 App 确认。

## 遇到异常

- `screen_off` 或锁屏时，请用户点亮或解锁。遇到 `rotation`，恢复竖屏后重新取图。
- 触控返回 `contact` 或 `device busy` 时，等现有操作结束，再根据新画面决定下一步。网络在操作途中断开时，动作可能已经发生。先重连并截图确认，尤其注意发送、删除和其他有副作用的操作。
- 遇到验证码、登录挑战、授权或条款确认，交给用户处理。只执行用户已授权的操作。
